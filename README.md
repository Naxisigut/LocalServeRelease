本仓库是LocalServe的发布仓库。

### 应用简介

LocalServe 是一款 macOS 桌面应用。不需要命令行，就可以把本地文件夹发布成浏览器能打开的站点，适合预览静态页面和本地前端项目。

主要功能：

- **本地站点**：选择文件夹，设置端口后启动，在本机浏览器中访问。
- **局域网访问**：同一网络上的手机或其他设备可以通过本机 IP 打开站点。
- **自定义域名**：为站点配置本地域名，并由应用写入 hosts。
- **反向代理**：把指定路径转发到其他本地服务，方便前后端一起预览。
- **文件分享**：把本地文件分享给同一局域网中的设备，扫码即可下载。
- **常驻运行**：支持菜单栏托盘、关闭窗口后继续运行，以及登录时自动启动。

## English

### About this repository

This repository is the release repository for LocalServe.

### About the app

LocalServe is a macOS desktop app. It publishes a local folder as a site you can open in a browser, without using the command line. It is meant for previewing static pages and local front-end projects.

Main features:

- **Local sites.** Pick a folder, set a port, and open the site in a browser on this Mac.
- **LAN access.** Phones and other devices on the same network can open the site through this Mac’s IP address.
- **Custom domains.** Give a site a local domain name, which the app writes into the hosts file.
- **Reverse proxy.** Forward selected paths to other local services so front end and back end can be previewed together.
- **File sharing.** Share local files with devices on the same network. Scanning a QR code starts the download.
- **Background use.** The app can stay in the menu bar, keep running after the window closes, and start when you log in.
